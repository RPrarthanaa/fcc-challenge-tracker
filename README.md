## 📖 About

As an avid lover of freeCodeCamp, I was excited when they introduced their daily challenges. I decided to create an application that saves these challenges, along with monthly statistics and overall progress, so that every day of practice is recorded and my consistency is easy to see.

This is a full-stack project: a React frontend, a Node.js and Express REST API, and a MySQL database, all deployed online.


## ✨ Features

- 💾 Save your freeCodeCamp daily challenges
- 📅 View monthly statistics
- 📈 Track overall progress over time

## 💡 Why This Stack?

- **React.js**: The tracker has many pieces that update together, such as a daily list, monthly stats and an overall progress view. React's component-based approach lets me build each piece once and reuse it, and its state handling keeps the UI in sync whenever new data is saved.
- **JavaScript across the whole stack**: Using Node.js on the backend means one language from the browser to the server. That cuts context switching and makes it easier to share logic and data shapes between frontend and backend.
- **Node.js and Express.js**: Express is minimal and unopinionated, which makes it a good fit for a clean REST API. Node handles many lightweight requests efficiently, which suits an app made of small, frequent reads and writes.
- **MySQL and SQL**: Challenge records are structured and relational (dates, statuses, completion data), which maps naturally to tables.
